# Pakistan E-Commerce Performance Dashboard

## Project Overview
This project focuses on analyzing a comprehensive e-commerce dataset from Pakistan to evaluate sales performance, order fulfillment, and operational efficiency. Using Tableau, I developed an interactive executive dashboard to transform raw transactional data into centralized, actionable business intelligence.

---

## The Business Problem Solved
* **Data Fragmentation:** High-volume marketplace transactions were trapped in raw data tables, creating a major blind spot for stakeholders tracking real-time PKR revenue velocity.
* **Operational Bottlenecks:** The operations team lacked visibility into order failure rates, making it difficult to determine whether transaction drop-offs were caused by specific payment gateways or customer cancellation trends.

---

## Core Features & Dashboard Architecture
* **Executive KPI Panel:** Tracks core high-level metrics including Total Gross Revenue (PKR), Total Orders Placed, and the Order Completion Efficiency Rate.
* **Revenue Trend Analysis:** A continuous monthly timeline line chart designed to map revenue spikes and identify seasonal purchasing patterns.
* **Product Category Performance:** A ranking horizontal bar chart that isolates top revenue-generating product segments to aid in inventory alignment.
* **Payment Gateway Matrix:** A multi-dimensional stacked bar chart analyzing payment methods (COD, EasyPaisa, JazzCash) against final order fulfillment statuses to uncover transaction friction.
